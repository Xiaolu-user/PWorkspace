# 安装与使用

## 下载和安装

从[官方 Releases 页面](https://github.com/Xiaolu-user/PWorkspace/releases)下载 `大内总管-1.0.0-Setup.exe`。当前提供 Windows 10/11 x64 安装包，可选择安装位置。

安装包尚未进行代码签名，Windows 可能显示未知发布者提示。请确认下载来自本仓库，并与同版 `SHA256SUMS.txt` 校验一致后再运行。PowerShell 校验命令：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\大内总管-1.0.0-Setup.exe'
```

## 第一次使用

全新用户的待办、笔记、链接、课程、健身计划与训练记录为空，仅提供 64 个预置健身动作。

1. 在“今日待办”点击加号记录事项。“每日必做”每天重置，未完成时优先显示。
2. 点击“本周课程”的空状态进入课表引导，设置学期、开学日期和课程。
3. 点击“今日健身”的空状态进入循环引导，再添加常用训练内容。
4. 在“快捷方式”添加应用或网址；“常用资料”保存文件／文件夹入口。
5. 设置页可调整主题、背景、字号、关闭行为及开机启动。天气需自行选择城市后联网获取。

## 备份与换电脑恢复

在旧电脑的设置页创建手动备份，将导出的 `.db` 文件单独保存到安全位置。在新电脑安装应用，打开“设置”，点击“选择备份并恢复”，选择该文件并确认。

恢复会用备份中的数据替换当前业务数据，执行前自动保留当前数据快照。恢复完成后，待办、笔记、课程、健身记录、快捷方式配置和外观设置会一同恢复。

备份包含个人内容及上传到应用中的图片，请妥善保管。数据库未加密，备份也不是加密文件。备份不包含快捷方式指向的应用程序、资料原文件或原文件夹；换电脑后需要自行迁移这些内容，并调整失效路径。

每天首次启动会创建自动备份，保留最近七份。手动备份及恢复前快照不自动清理。

## 为什么重装后仍有原数据

默认数据目录为 `%APPDATA%\PersonalWorkbench\data`，与程序安装目录分开。覆盖安装、卸载后重装都会保留该目录，避免丢失已有内容；这不表示安装包携带了其他人的数据。

如需从零开始，请先手动备份，在设置页打开数据目录并记下位置，然后从托盘完全退出应用。将上述 `data` 文件夹重命名留存，再启动应用，即会创建空数据。不要在程序运行时移动数据库。

## 提醒与关闭

窗口关闭后可选择继续在托盘运行；提醒需要应用处于运行状态。完全退出或电脑关机时不发送提醒。Windows 通知设置及勿扰模式可能影响系统提示。

## 数据与联网

业务数据保存在本机 SQLite 数据库中，无账号和云同步服务。天气由 Open-Meteo 提供，搜索城市和请求天气时会联网；未选择城市时不会请求天气。点击外部网址会使用系统浏览器。
