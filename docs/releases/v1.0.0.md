# 大内总管 v1.0.0

首个正式版本：把待办、灵感、课程、健身和常用入口放进一个本地桌面工作台。

## 主要功能

- 每日必做、日期待办、提醒和日历。
- 纯文本笔记、应用／网页快捷方式、本地资料入口。
- 学期课表、多周排课、临时调课和冲突提示。
- 健身循环、64 个预置动作、训练记录和跨月／全年统计。
- 主题背景、字号调整、托盘运行和可选开机启动。
- 本地存储、自动备份、手动备份和恢复。

## 下载

Windows 10/11 x64：下载本页附件 `DaneiZongguan-1.0.0-Setup.exe`，校验值见 `SHA256SUMS.txt`。

安装包未进行代码签名，Windows 可能提示未知发布者。请确认来源并核对校验值。[安装及数据迁移说明](https://github.com/Xiaolu-user/PWorkspace/blob/v1.0.0/docs/使用说明.md)。

## 数据说明

全新使用不预置个人数据，仅保留动作库；点击首页课程和健身空状态可开始设置。覆盖安装或卸载重装保留已有本机数据。已有用户请先备份，再升级；换电脑可在设置页导入原 `.db` 备份。

备份不包含快捷方式指向的外部文件和应用。不要将自己的数据库或备份上传到公开仓库。

## 当前范围

本版提供 Windows x64 安装包；无云同步、账号或自动更新。系统通知、外部程序关联、安装与覆盖升级体验受本机 Windows 环境影响。
