# 拾光工作台 / PWorkspace

Windows 上离线运行的个人桌面工作台，用于管理待办、纯文本笔记、应用与网页快捷方式、学期课程、健身计划和本地资料入口。

当前版本：**v0.1.0 开发基线**。主要功能已实现，可进行开发预览；完整桌面回归、安装包验证和日常试用尚未完成，不应视作已验收的正式版本。

## 技术结构

- 界面：Vue 3、TypeScript、Vue Router、Pinia、Element Plus。
- 桌面：Electron、受控的 preload/IPC 接口。
- 本地数据：SQLite、better-sqlite3。
- 工程：electron-vite、electron-builder、Vitest、Playwright。

```text
src/main       窗口、业务服务、数据库、备份恢复、日志
src/preload    向界面提供有限的桌面能力
src/renderer   页面、组件、状态和样式
src/shared     类型、通信通道、日期工具
tests          数据读写、输入规则、备份与迁移测试
scripts        开发、构建、图标和桌面测试入口
```

## 开发预览

要求 Windows x64、Node.js 22.12 或更新的兼容版本，以及 Git。首次安装依赖需要联网，软件本地功能支持离线使用。

在项目目录执行：

```powershell
npm.cmd ci
node scripts/dev.cjs
```

也可以在 VS Code 中打开项目，按 **Ctrl + Shift + B**，选择“拾光工作台：实时预览”。保持启动终端运行，保存页面或样式后自动更新，修改主进程或 preload 时会重新启动桌面程序。修改前先保存正在编辑的笔记。

开发预览的数据保存在项目的 `.cache/dev-profile`，与默认安装版数据分开。若 PowerShell 中的 `npm` 启动脚本异常，可先尝试 `npm.cmd`；依赖已经安装时，可以直接使用上述 `node` 启动命令。

## 检查与打包

```powershell
npm.cmd run typecheck
node scripts/test.cjs
node scripts/build.cjs
node scripts/smoke.cjs
node scripts/build.cjs pack
node scripts/smoke.cjs --packaged
node scripts/build.cjs dist
```

- 数据测试使用 Electron 的 Node 运行时，匹配 SQLite 原生驱动 ABI。
- 桌面测试会启动真实窗口，数据保存在 `.cache/smoke-*`，报告和截图写入 `test-results`。自动化中会替代系统文件选择和浏览器打开的响应；原生对话框与真实浏览器还需要人工验收。
- `pack` 输出可执行目录；`dist` 输出 Windows NSIS 安装包。产物位于 `release`。
- 安装或升级 Electron 后需要重建原生依赖：`npm.cmd run postinstall`。`npm ci` 也会执行此步骤。

## 数据与备份

默认安装版将业务数据保存在 `%APPDATA%/PersonalWorkbench/data`，日志位于同级的 `logs` 目录。设置页可以查看并打开数据目录。

- 每天首次启动创建一次自动备份，保留最近七份。
- 设置页支持手动选择位置备份；手动备份不自动删除。
- 恢复前校验备份的应用标识、结构版本和完整性，并保留恢复前快照。
- `.cache`、数据库、日志、依赖与构建产物均不提交到 Git。GitHub 中保存源码，个人业务数据通过软件自身的备份功能保存。

## Git 协作约定

远程仓库：<https://github.com/Xiaolu-user/PWorkspace>

当前以 `main` 保存阶段基线。每完成一个功能或修复，检查差异、运行相关验证后提交并推送；提交说明准确区分开发中与已验收状态。较大功能另开 `codex/...` 分支。

```powershell
git status
git diff
# 检查后，在 VS Code 中暂存本次相关文件
git commit -m "fix: 修复未保存笔记的退出保护"
git push
```

阶段汇报包括完成内容、验证结果、未完成项和提交编号。正常同步使用普通 push；保留已有历史，不使用强制推送覆盖远程提交。

每次提交使用简短中文标题说明本次目的，在正文列出主要功能变化、相关验证和必要的限制。提交说明随 `git push` 一起上传，可在 GitHub 的 Commits 页面点击提交查看；一次推送可以包含多次提交，改动说明按提交保存。

本机访问 GitHub 使用代理 `http://127.0.0.1:7897`，已通过当前仓库的本地 `http.proxy` 配置启用；推送前需保持对应代理程序运行。该配置不提交到仓库，也不修改其他项目。更换代理端口时更新本地配置；网络可直接访问 GitHub 后可执行 `git config --local --unset http.proxy` 移除。

## 新版首页使用说明

- 左侧为图标导航，鼠标悬浮或键盘聚焦显示功能名。
- 时间取本机系统日期和时分；今日待办展示截止日期为今天的任务（含已完成项），以及已触发提醒且尚未完成的其他日期事项。首页新增任务默认今天；逾期任务保留单独入口。
- 日期右侧的日历图标打开月历，支持切换月份、返回今天；选择某天后，可查看、添加、编辑和完成当天待办。有事项的日期显示数量，与“我的待办”和今日待办共用数据。
- 月历标题旁可输入数字，选择年、月、日，点击“跳转”前往当前选中日期的相应时间以后。月末及闰日按目标月最后一天截断；空值、负数和超出 1900 至 9999 年的日期不会跳转。
- 日期数字上方显示公历、农历节日、纪念日和节气；放假与补班分别标“休”和“班”。数据通过 [lunar-typescript](https://github.com/6tail/lunar-typescript) 离线计算和读取，2026 调休已与[国务院办公厅通知](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)核对。未收录调休的年份会明确提示，不推测放假安排。
- 弹窗框体、表单控件及文字默认放大，较小窗口可滚动。设置中的“模块与文字大小”支持全局字号、弹窗尺寸和字号，以及七个首页模块各自的缩放和文字大小；保存后生效，支持恢复默认，随数据库备份恢复。
- 待办可选填事项时间，设置准时、提前 5 / 10 / 15 / 30 分钟、1 小时、1 天或自定义 0 至 43200 分钟提醒。表单显示实际提醒时间，新增或改期时不接受已过去的提醒时间。提醒按本机时区计算，设置随数据库备份恢复，旧数据库会先备份再升级。
- 提醒由桌面主进程每 15 秒检查一次，窗口收起到托盘仍然生效；完全退出时不发送，未发送且未完成事项会在下次启动或电脑休眠唤醒后补发。已完成、删除或取消提醒的事项不发送；已发送状态会保存，修改事项日期、时间或提前时长后重新安排。请在 Windows 中允许工作台通知；系统勿扰模式可能影响通知展示。
- 到达提醒时间时，事项在今日待办、我的待办和所属日期日历中置顶、高亮并闪烁。点击“我已知晓”停止闪烁，保持置顶高亮直到完成；确认状态在刷新、重启和备份恢复后保留。改期或调整提醒时长会重置确认状态。
- 快捷方式支持添加本机 `.exe` / `.lnk` 应用，以及 http/https 网页；本机图标从系统读取，网页使用名称首字作为离线图标。网页可在“常用链接”中修改。
- “学期课程”可设置开学日期、周数、星期、时间、起止周和单双周；包含开学日的周一作为第一周起点。首页呈现本周概览，点击星期查看当天课程。
- “制定计划”设置七天循环健身安排，未填写的天视为休息日。首页只显示当天信息，不提供训练开始按钮。
- 灵感区点击即可输入，Ctrl+Enter 或“记录”保存为笔记，首行自动作为标题；离开首页和真正退出前处理未保存内容。
- 资料区通过系统选择器添加文件或文件夹，点击使用默认程序打开。当前实现为**原位置文件入口**，不复制文件，也不支持拖入上传；文件移动后需要重新添加。删除入口不会删除原文件。
- 课程、健身和文件入口保存在 SQLite 设置中，与现有备份一起恢复。**数据库备份不包含入口指向的资料文件或应用程序**，这些文件需要自行备份。
- 首页在宽窗口中呈现三列不等宽布局；较窄窗口将右侧模块放到下一行，内容较多的区域支持滚动。

首页专项验证：`node scripts/home-smoke.cjs`；截图及报告保存在 `test-results/home`。测试数据与日常开发数据隔离，不会向你的工作台填入示例记录。

日历与提醒验证：`node scripts/calendar-smoke.cjs`；截图及报告保存在 `test-results/calendar`。覆盖按日期创建、编辑、完成、自定义跨日提醒、月份切换、小窗口布局及重启持久化；后台提醒使用真实主进程轮询，系统通知使用替身，Windows 通知的实际展示仍需本机试用。

显示与提醒确认验证：`node scripts/display-smoke.cjs`；截图及报告保存在 `test-results/display`。覆盖按日/月/年跳转、节假日标注、默认放大的弹窗、逐模块大小配置、跨日期提醒置顶与确认、完成后解除，以及配置和确认状态的重启持久化。
